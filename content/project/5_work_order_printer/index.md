A browser-based print utility that converts CSV or XLSX work orders into one A5 page per data row. Files are processed locally in the browser, with selectable columns, portrait or landscape layouts, automatic scaling, and five production-stage signature fields.

<!--more-->

## Highlights

- **One row, one page:** Turns every work-order row into an individual A5 sheet.
- **Flexible layout:** Supports A5 portrait and landscape, column selection, optional headers, empty-field filtering, and scale-to-fit.
- **Production sign-off:** Includes signature fields for winding, rubber coating, tape wrapping, vulcanization, and the supervisor.
- **Private by design:** Reads source files locally in the browser without uploading them.
