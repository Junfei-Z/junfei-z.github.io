An open-source, local-first bridge for moving text, files, and unfinished development work between devices. It pairs browser clients over your local network and uses GitHub plus inspectable handoff packages to continue agent-assisted work on another computer.

<!--more-->

## Two focused workflows

- **Text and file transfer:** Run ClipBridge on one Mac or Windows relay computer, then pair phones and other devices from a browser on the same local network.
- **Agent Handoff:** Run ClipBridge on both computers. The sender packages project changes and working context; the receiver clones or safely updates the GitHub repository, verifies the package, and continues the work.
- **Visible by design:** Project state, context, and every handoff step remain inspectable instead of being hidden behind an opaque sync service.
- **Open source:** Use the hosted project guide, download the Mac or Windows launcher, or inspect the implementation on GitHub.
