一款开源、本地优先的跨设备工作流工具：在局域网内传输文字和文件，并通过 GitHub 仓库与可检查的交接包，把未完成的 Agent 协作工作交到另一台电脑继续。

<!--more-->

## 两条清晰的工作流

- **文字与文件传输：** 只需在一台 Mac 或 Windows 中转电脑上运行 ClipBridge，手机和其他设备即可通过同一局域网内的浏览器完成配对。
- **Agent Handoff：** 两台电脑都需要运行 ClipBridge。发送端打包项目改动和工作上下文；接收端克隆或安全更新 GitHub 仓库，检查交接包后继续工作。
- **过程清晰可查：** 项目状态、上下文与每一步交接都可以检查，不依赖不透明的后台同步。
- **开源可用：** 可以阅读在线项目指南、下载 Mac 或 Windows 启动程序，也可以直接查看 GitHub 源代码。
